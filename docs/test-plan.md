# ماتریس تست

همه‌ی تست‌ها قبل از Production اجرا می‌شوند؛ تست‌های دسترسی و امنیتی از همان فاز C به CI اضافه می‌شوند.

## رفتار مورد انتظار در خطاهای آپلود

| سناریو | رفتار مورد انتظار |
| --- | --- |
| قطع اینترنت/شبکه | از آخرین offset معتبر ادامه می‌یابد |
| قطع ارتباط با SAN | خطای قابل تکرار؛ نشست خراب نمی‌شود؛ alert |
| پر شدن فضای موقت | آپلود جدید رد می‌شود؛ آپلودهای جاری با خطای واضح متوقف؛ alert |
| Restart container/VM | نشست‌ها از DB و فایل بازیابی می‌شوند |
| درخواست تکراری / قطعه‌ی تکراری | بدون اثر جانبی (idempotent) |
| offset ناهم‌خوان | رد با خطای tus؛ کلاینت offset را از سرور می‌شنود |
| قطع Worker وسط اسکن | job دوباره اجرا می‌شود؛ نه تکراری نه گمشده |
| انقضای نشست | رزرو quota آزاد و فایل موقت پاک می‌شود |

## عملکردی

آپلود یک فایل کوچک، چند فایل، پوشه، دانلود، ایجاد پوشه، تغییر نام، انتقال، حذف، بازیابی، نسخه‌بندی، اشتراک و لغو اشتراک.

## آپلود حجیم

۱۰۰ MB، ۱ GB، ۵ GB و در صورت تأیید سازمان ۲۰ GB. در هر تست: قطع شبکه، restart سرویس، و ادامه. اندازه‌گیری: زمان hash و اسکن، RAM پروسس‌ها، فضای موقت.

## امنیت و دسترسی

- مدیر منطقه‌ی A هرگز کاربر، فایل، گزارش یا Audit منطقه‌ی B را نمی‌بیند (همه‌ی endpointها).
- کاربر عادی با تغییر شناسه فایل/پوشه/نسخه/نشست آپلود (IDOR) به چیزی دست نمی‌یابد.
- سهمیه: از سقف حجم و سقف تعداد فایل نمی‌توان رد شد (آپلودهای هم‌زمان هم نمی‌توانند با هم از سقف عبور کنند).
- سیاست فایل: پسوند ممنوع، فایل با پسوند جعلی (magic bytes ناهماهنگ)، فایل آلوده‌ی آزمایشی (EICAR)، zip bomb کنترل‌شده، آرشیو رمزدار، بیش از سقف اندازه.
- Path traversal در نام فایل و پوشه؛ دانلود فایل Quarantine/Rejected ممنوع؛ دسترسی پس از لغو share؛ استفاده مجدد از توکن دانلود منقضی‌شده.
- غیرفعال کردن کاربر: sessionها، آپلودهای جاری و shareهای مقصد او فوراً لغو می‌شوند.
- هدرهای دانلود و نام فایل فارسی (`filename*`).

## فشار

کاربران هم‌زمان، آپلودهای هم‌زمان، سرعت دانلود، CPU/RAM، IOPS و Latency SAN، فضای موقت، فشار روی PostgreSQL، طول صف اسکن.

## پایداری

Restart container و VM، قطع شبکه، قطع کنترل‌شده‌ی Storage، توقف Worker، پر شدن فضای موقت، شکست اسکن، شکست Backup.
