# پرسش‌های باز و تصمیم‌های گرفته‌شده

## تصمیم‌های گرفته‌شده (از طرف سازمان)

- ساختار: یک مدیر ارشد، دو مدیر منطقه (هر کدام فقط زیرمجموعه‌ی خودش)، کاربران عادی به تعداد زیاد (ADR-0006).
- برای همه به جز مدیران ارشد، حجم کل آپلود و حداکثر تعداد فایل هنگام تعریف کاربر مشخص می‌شود.
- هر نوع فایلی که مشکل‌ساز نباشد مجاز است (بدون allowlist).
- فیلدهای کاربر: نام، نام خانوادگی، واحد سازمانی، ایمیل و موارد دیگر.
